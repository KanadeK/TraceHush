# Changelog

All notable changes follow Keep a Changelog style. The project uses semantic versioning.

## 0.1.0 — 2026-08-27

### Added

- Offline audit for Playwright trace ZIP members.
- Trace-aware structured detection for HAR headers, cookies, queries, URLs, and form actions.
- JWT, GitHub token, AWS access-key, named-field, and explicit-literal detection.
- Non-leaking console and JSON reports with deterministic fingerprints.
- Atomic text-redacted ZIP copies with integrity check and second audit.
- Explicit binary residual-risk reporting.
- Archive resource and unsafe-name boundaries.
- Reproducible safe/leaky examples.
- Windows and Ubuntu CI, locked dependencies, wheel/sdist packaging, and release assets.
